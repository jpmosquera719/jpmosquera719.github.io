# Portafolio de Juan Pablo Mosquera Pascuas

1. **Agregar un proyecto:** copia un bloque en `data/proyectos.json`, cambia sus campos y pon las imágenes en `assets/img/`.
2. **Imágenes, PDF y modelos:** usa rutas relativas como `assets/img/foto.jpg`, `assets/docs/archivo.pdf` o `assets/models/modelo.glb`.
3. **Cambiar colores y fuente:** edita las variables al inicio de `css/style.css`.
4. **Activar GitHub Pages:** Settings → Pages → Deploy from a branch → rama `main`, carpeta `/ (root)` → Save.
5. **Ver en local:** ejecuta `python -m http.server` en esta carpeta y abre `http://localhost:8000` (si abres el archivo directo, los proyectos no cargan).
